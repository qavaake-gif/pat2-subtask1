What is Morse Code?
Morse Code is a method of communication that uses a series of short and long signals to represent letters, numbers, and symbols. These signals are commonly called dots (short signals) and dashes (long signals). Morse code can be sent using sound, light, radio waves, or written symbols. It was widely used in telegraph systems before modern communication technology developed.

Historical Background of Morse Code
Samuel Morse created Morse code in the 1830s and 1840s together with Alfred Vail. The code was developed to improve long-distance communication through the telegraph.
Before Morse code, sending messages over long distances was slow because people depended on letters delivered by horse, ship, or train. The invention of the telegraph allowed electrical signals to travel through wires quickly. Morse code was created so that these electrical signals could represent letters and words.

The first official Morse code message was sent in 1844 and read:
“What hath God wrought?”
Morse code became very important in communication systems used by ships, the military, railways, and emergency services for many years.

How the Morse Code System Works
Telegraphy uses combinations of dots and dashes to represent each letter and number.
A dot (·) is a short signal.
A dash (—) is a longer signal.
Each letter has its own unique pattern.
Examples
Letter Morse Code
A          · —
B          — · · ·
C            — · — ·
S            · · ·
O            — — —
For example, the famous distress signal SOS is written as:
SOS = . . . _ _ _ . . .
When sending Morse code:
Short pauses separate dots and dashes within a letter.
Longer pauses separate letters.
Even longer pauses separate words.
Morse code can be communicated in different ways, including:
Beeping sounds
Flashing lights
Radio signals
Tapping sounds
Today, Morse code is still used by some radio operators, the military, and in emergency situations where other communication systems may fail.
